# python-practicas

Repositorio de prácticas de Python, con ejercicios sencillos para aprender lo básico del lenguaje.

## Índice de prácticas

### Semana 0
- [`semana-00/edad.py`](semana-00/edad.py): pide tu nombre y año de nacimiento y calcula tu edad.

### Semana 3
- [`semana-03/limpieza_de_texto.py`](semana-03/limpieza_de_texto.py): limpia un nombre con `strip()` y muestra versiones en mayúsculas/minúsculas y longitudes.
- [`semana-03/credencial.py`](semana-03/credencial.py): genera una credencial en una caja de texto con iniciales y número de caracteres.
- [`semana-03/buscador_de_palabras.py`](semana-03/buscador_de_palabras.py): busca, cuenta y sustituye palabras dentro de una frase.
- [`semana-03/tabla_de_precios.py`](semana-03/tabla_de_precios.py): imprime una tabla de productos y precios con columnas alineadas.
- [`semana-03/diario_de_texto.py`](semana-03/diario_de_texto.py): escribe varias líneas en `diario.txt` en modo *append* y luego las relee numeradas.
- [`semana-03/gastos_json.py`](semana-03/gastos_json.py): guarda una lista de gastos en `gastos.json`, la recupera y calcula el total.
- [`semana-03/carga_segura.py`](semana-03/carga_segura.py): carga `gastos.json` controlando con `try/except` el caso de que el archivo no exista.
